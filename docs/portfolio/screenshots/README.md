# Screenshots

Capture screenshots after running `npm run dev` and place them here with the
filenames referenced in the root README:

- `hero-landing.png`
- `guest-landing.png`
- `booking-calendar.png`
- `admin-dashboard.png`
- `double-booking-warning.png`
- `mobile.png`

Recommended dimensions: 1600×1000 for desktop captures, 400×800 for mobile.
